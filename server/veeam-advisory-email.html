Vulnerability Details
CVE-2026-108142
Authorization Bypass on CDP Coordinator Service
  • Severity: Critical, CVSS v4.0 9.1.
  • Impact: An unauthenticated attacker may bypass authorization controls on the CDP Coordinator Service.
  • Affected Deployment Type: Windows-based Veeam Backup & Replication and Veeam Software Appliance.
  • Affected: Veeam Backup & Replication 13.1.1.18 and earlier 13.1 builds; Veeam Backup & Replication 13.0.2.29 and earlier 13.0 builds.
  • Fixed: Veeam Backup & Replication 13.1.2 (Build 13.1.2.57) and Veeam Backup & Replication 13.0.3 (Build 13.0.3.63).
  • Source: Veeam KB4738 — Reported through HackerOne.
  • Note: Older versions (12.x) are not affected.

For vendor details, see Veeam KB4738.

CVE-2026-108140
Arbitrary File Write through Relative Path Traversal
  • Severity: Medium, CVSS v4.0 5.9.
  • Impact: An authenticated Restore Operator who controls a backed-up NAS share may write attacker-controlled files to arbitrary locations on the backup server through relative path traversal.
  • Affected Deployment Type: Windows-based Veeam Backup & Replication and Veeam Software Appliance.
  • Affected: Veeam Backup & Replication 13.1.1.18 and earlier 13.1 builds; Veeam Backup & Replication 13.0.2.29 and earlier 13.0 builds.
  • Fixed: Veeam Backup & Replication 13.1.2 (Build 13.1.2.57) and Veeam Backup & Replication 13.0.3 (Build 13.0.3.63).
  • Source: Veeam KB4738 — Reported through HackerOne.
CVE-2026-108141
Arbitrary File Write through Relative Path Traversal
  • Severity: Medium, CVSS v4.0 5.9.
  • Impact: An authenticated Restore Operator who controls a backed-up NAS share may write attacker-controlled files to arbitrary locations on the backup server through relative path traversal.
  • Affected Deployment Type: Windows-based Veeam Backup & Replication and Veeam Software Appliance.
  • Affected: Veeam Backup & Replication 13.1.1.18 and earlier 13.1 builds; Veeam Backup & Replication 13.0.2.29 and earlier 13.0 builds.

CVE-2026-105477
Local Privilege Escalation in Veeam Agent for Linux
  • Severity: High, CVSS v4.0 7.3.
  • Impact: A local privilege escalation vulnerability affecting Veeam Agent for Linux installations managed by a Veeam Backup & Replication instance.
  • Affected: Veeam Agent for Linux 13.1.1.4 and earlier 13.1 builds.
  • Fixed: Veeam Agent for Linux 13.1.2 (Build 13.1.2.11).
  • Source: Veeam KB4738 — Reported through HackerOne.
  • Note: Older versions (13.0.x and 6.x) are not affected.
Affected Products and Versions
  • Veeam Backup & Replication 13.1: Builds 13.1.1.18 and earlier.
  • Veeam Backup & Replication 13.0: Builds 13.0.2.29 and earlier.
  • Veeam Software Appliance: Vulnerable affected deployments.
  • Veeam Agent for Linux: Version 13.1.1.4 and earlier 13.1 builds.
Fix
  1. Veeam Backup & Replication: Upgrade to version 13.1.2 (Build 13.1.2.57) or version 13.0.3 (Build 13.0.3.63).
  2. Veeam Agent for Linux: Upgrade to version 13.1.2 (Build 13.1.2.11).
  3. Validation: Verify CDP, backup, restore, replication, NAS backup, and agent-management functions after patching.

Workaround/Temporary fix/Mitigation
  • Restrict Veeam management interfaces to trusted administrative networks.
  • Review and limit Restore Operator permissions.
  • Monitor CDP Coordinator Service activity for unauthorized access attempts.
  • Monitor NAS backup restore operations for suspicious file-write activity.
  • Monitor Linux agents for privilege-escalation attempts.
  • Temporary controls reduce risk but do not replace vendor updates.

Honeywell Recommended Action
  • Inventory all Veeam Backup & Replication servers, CDP deployments, and Veeam Agent for Linux installations.
  • Immediately remediate systems affected by CVE-2026-108142 due to the critical authorization bypass vulnerability.
  • Review Restore Operator role assignments and remove unnecessary privileges.
  • Upgrade all affected Veeam Agent for Linux systems.
  • Validate backup, restore, CDP, NAS backup, and replication functionality after remediation.
